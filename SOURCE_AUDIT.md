# Source and dependency notes

This repository provides the modified KDE WebDriver source. Its upstream base
and fork changes are identified in [FORK.md](FORK.md) and
[MODIFICATIONS.md](MODIFICATIONS.md).

The runtime source-offer mechanism verifies an explicit manifest against the
installed component files. A distributor or network operator must independently
establish the complete Corresponding Source and license obligations for the
actual Python, native, operating-system, and packaging dependency set used in
that deployment. This repository does not claim that an arbitrary environment
has been audited or is release-ready.
